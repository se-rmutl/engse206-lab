# Submission Register — หน้าส่งงานหน้าเดียวของกลุ่ม

> วางไฟล์นี้ที่ `submissions/submission-register.md` ใน Team Repo แล้วกรอกให้ครบ **ภายใน [วันที่ผู้สอนกำหนด]**
> ถ้า repo ของกลุ่มยังไม่มีไฟล์นี้ (สร้างจาก template รุ่นเก่า) ให้สร้างไฟล์ใหม่ที่ path นี้ — ถ้ามีอยู่แล้ว ให้วางทับ
> ผู้สอนตรวจจากหน้านี้หน้าเดียว — งานที่ไม่มีลิงก์ในหน้านี้ถือว่า "ไม่ได้ส่ง"
> ลิงก์ทุกอันให้ใช้ **ลิงก์แบบ permalink ที่มี commit hash** (กดปุ่ม `y` บนหน้าไฟล์ใน GitHub แล้วคัดลอก URL) เพื่อให้ผู้สอนตรวจฉบับที่ส่งจริง
> **อย่าใส่รหัสนักศึกษาในหน้านี้หรือในชื่อไฟล์** — repo เป็นสาธารณะ ผู้สอนจับคู่ชื่อกับรหัสจาก Google Sheet ของรายวิชา

## กติกา

1. **ฉบับที่ตรวจ** — ผู้สอนตรวจตาม commit ในช่อง "Commit ฉบับส่ง" ถ้าว่าง ผู้สอนตรวจตามสภาพ repo ณ วันครบกำหนดของสัปดาห์นั้น
2. **แก้หลังกำหนด** — แก้ได้ แต่ห้ามเขียนทับโดยไม่บันทึก ให้ใส่ทั้งสอง commit ผู้สอนเป็นผู้ตัดสินว่านับฉบับไหน
3. **ไฟล์ผิด path** — ใช้ได้ ถ้าใส่ลิงก์ไฟล์ที่ใช้แทนในช่อง "ไฟล์หลัก" และเขียนเหตุผลในหมายเหตุ
4. **งานที่ทำรวมในสัปดาห์อื่น** (เช่น W10 ที่ทำรวมในเอกสาร W11) — ลิงก์ไปยังหัวข้อนั้นและเขียนในหมายเหตุ
5. **งานที่ส่งนอก repo** — ใส่ลิงก์และวันที่ส่งจริง สถานะ `ส่งทางอื่น`
