# Activity W05-C — Prioritization Matrix

> **เป้าหมาย:** ให้ priority โดยมีเหตุผลจาก value, risk, urgency และ dependency

## MoSCoW Guide

| Priority | ใช้เมื่อ |
|---|---|
| Must | ขาดไม่ได้ต่อเป้าหมายหลัก กฎ ความปลอดภัย หรือ workflow |
| Should | สำคัญมาก แต่ยังมีวิธีทำงานชั่วคราว |
| Could | มีคุณค่า แต่เลื่อนได้ |
| Won't yet | ยังไม่ทำใน scope นี้ หรือหลักฐานยังไม่พอ |

## Worksheet

|---|---|---|---|---|---|---|

## Rule

ถ้า requirement สำคัญแต่ dependency ยังไม่ชัด ให้ใช้ `Needs Follow-up` ไม่ใช่แกล้งทำเหมือนยืนยันแล้ว
